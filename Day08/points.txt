Example of Factory Pattern
--------------------------
Factory Pattern comes under Creational Pattern, where we talk about object creation, it abstracts and centralizes object creation. Instead of creating the object using the new operator the client code delegates this responsibility to a specialized factory class or method

This pattern supports loose coupling and adheres to the Open / Close Principle meaning your system for extension (adding new type of objects) but closed for modification (no option to rewrite the existing business logic)

Behavioral Pattern
------------------
Observer Pattern
----------------
Observer pattern is a behavioral design pattern that defines a one-to-many dependency between objects. It ensures that when an object changes its state all its dependents are automatically notified.


Structural Pattern
------------------
Adapter Design Pattern
----------------------
Adapter Design pattern is a structural design pattern that allows object with incompatible interfaces to collaborate. It acts as a translator or a bridge wrapping an existing class with a new interface so that it matches what a client system expects
