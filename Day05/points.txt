Marshal -> dependent on version of python interpreter

internally marshal is used by python to read and write the compiled bytecode (.pyc files)

Version Dependency - this format of serialized data is not guaranteed to be portable across python versions. A .pyc file created in 3.9 may not be readable in python 3.11 because the bytecode format changes

its mainly intended for python's own internal use not for general purpose object serialization

for cross platform serialization we should use pickle or json which are designed for compatibility and human readability

PICKLE
------
serialization (pickling) converts python objects into byte stream

a. it traverses the object recursively
b. stores the type information (eg. list, dict, custom class)
c. Handles references to avoid duplicating shared objects

Deserialization (unpickling) Reconstructs the original python object from the by stream

a. Reads the code and data from the stream
b. Recreates the object structure in memory

Protocols
a. Text based (older, human-readable)
b. Binary protocol (newer, faster, more-efficient)
c. latest protocol is chosen by default in modern python versions

Note - never unpickle data from untrusted sources, it can execute arbitrary code

2. shelve

shelve is a Python module that provides a persistent dictionary-like object.

It uses pickle internally to serialize objects, but gives you a key-value store interface (like a dictionary).

Keys must be strings, but values can be any picklable Python object (lists, dicts, custom classes, etc.).
